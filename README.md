# Ahmed Shawky | Frontend Developer Portfolio

A responsive, bilingual (English/Arabic) personal portfolio website built with HTML, CSS, and JavaScript.

🔗 **Live Demo:** [ahmedshawky10001-svg.github.io/portfolio-ahmed-shawky](https://ahmedshawky10001-svg.github.io/portfolio-ahmed-shawky/)

## ✨ Features

- **Bilingual support (EN/AR)** — instant language switch with saved preference (localStorage)
- **Fully responsive** design for desktop, tablet, and mobile
- **Animated typing effect** for the hero title
- **Scroll animations** — reveal-on-scroll sections and animated skill progress bars
- **Sticky header** with scroll progress bar and active nav-link highlighting
- **Smooth scrolling** navigation between sections
- **Contact form** with success toast notification
- **Back-to-top** button
- **Mobile-friendly** hamburger menu

## 📄 Sections

- Hero
- About Me
- Technical Skills
- Featured Projects
- Services
- Education & Certifications
- Contact
